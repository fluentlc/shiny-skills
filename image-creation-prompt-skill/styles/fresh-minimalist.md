# Style Template: 小清新风格插画模板 (Fresh Minimalist Flat Vector Style)

**Opening Line:**
```
Fresh and minimalist flat vector style educational infographic, [aspect_ratio], explaining [topic].
```

**Sections:**

```
=== TITLE STYLE ===
"[topic]" in modern, rounded sans-serif font, friendly and soft
Font color: pastel mint green
Texture: Flat digital fill, smooth edges, no heavy bevels

=== SCENE & LAYOUT ===
Composition: [choose one: horizontal step-by-step floating islands layout / left-to-right timeline on white / radial petal layout from center]
Background: Pure white or extremely pale off-white, clean and airy, plenty of negative space (breathing room).

=== MAIN CONTENT ===
[For each step, use STEP_N format. Each step sits on a small floating island with gentle shadow]

[STEP_N]
Visual: [a sleek minimalist icon representing this step — e.g., function bracket "()" with pulse lines / interlocking puzzle pieces / brain-shaped badge with embedded motif] placed on a soft [color] circular island with gentle shadow
Action: Cute flat vector illustration, simple shapes, soft gradients
Label: "[step name]" in clean sans-serif text inside a rounded text bubble or floating near the icon
[If not first step] Connection: simple curved line with soft gradient flow pointing from previous step

=== VISUAL STYLE ===
Material: Digital vector graphics, flat design with very subtle soft gradients (no heavy shading).
Render: Clean 2D Adobe Illustrator style, smooth curves, rounded corners on everything.
Colors: Fresh pastel palette (mint green, baby blue, lemon yellow, pale pink), high brightness, low saturation, very soothing and organic.

=== DECORATIVE ELEMENTS ===
Organic shapes like green leaves, water droplets, soft clouds, simple circles, and sparkles framing the corners or floating in the background to add a "fresh" atmosphere without clutter.

=== MOOD ===
Healing, healthy, organic, calm, refreshing, clean, lifestyle-oriented.

Quality: High-quality vector art, crisp edges, perfect color harmony, modern UI aesthetic | 8k, masterpiece, best quality, ultra-detailed, vector crisp, studio lighting, clean composition
```

**Fill-in rules:**
- Each step's island should use a distinct pastel color (lemon yellow → baby blue → pale pink) to differentiate stages at a glance
- Icons should be ultra-minimal: one or two geometric shapes, no complex illustrations
- Connections between steps should be soft, curved gradient lines — never sharp arrows
- Negative space is a design element: resist the urge to fill — keep the layout airy
