**Fill-in rules:**
- The object's torn layers should reveal structurally meaningful details — internal components, joints, connectors, or material layers that tell the story of how the object is built
- Layer count (N) should reflect object complexity: simple objects 4–5 layers, complex devices 6–8 layers
- Interior style mix (line-art + sumi-e + watercolor + pencil) creates a hybrid tactile aesthetic — all four modes should be referenced
- Background should be minimal and non-competing — the torn paper effect is the hero
