Whiteboard hand-drawn marker style educational illustration, [aspect_ratio], explaining [topic].

**Sections:**

```
=== TITLE ===
"[topic]" in bold black handwritten marker font

=== SCENE & LAYOUT ===
Layout: roadmap journey with arrows — horizontal left-to-right timeline showing progressive evolution, labeled "Stage 1 → Stage 2 → Stage 3" (or as many stages as needed), with bold curved arrow connecting all phases and upward-trending elevation graphic beneath the path
Background: Realistic whiteboard surface, soft reflection, subtle eraser smudges, slight shadow at edges
Frame: Aluminum whiteboard frame visible
Decorative elements: Hand-drawn arrows, circles, underlines, exclamation marks, lightbulbs, gears, speech bubbles in red and blue marker

=== MAIN CONTENT ===
Use simple hand-drawn cartoon doodles (marker sketch style)

[CONTENT_SECTION_N]
Character/Element: [a minimalist robot or abstract icon representing this step, with a relevant symbol on its chest or in hand]
Expression/State: [neutral / confident / triumphant], [specific visual cue, e.g., eyes as rectangles, mouth open, arms raised]
Props: [relevant objects: parentheses, clipboard with JSON, graduation cap, glowing badge, surrounding icons]
Visual: sketchy icon with motion lines indicating [code execution / orchestration / transformation]
Label: "[step name]" written as if quickly handwritten
Dialogue (speech bubble): "[step description in Chinese, 15–30 characters]"

=== KEY CONCEPTS ===
3 floating info boxes drawn as marker rectangles with uneven edges:
Box 1: "[concept 1]：[key attribute]"
Box 2: "[concept 2]：[key attribute]"
Box 3: "[concept 3]：[key attribute]"

=== WHITEBOARD STYLE ===
Real classroom whiteboard aesthetic, black base marker lines, red and blue emphasis strokes, visible stroke overlap, slight perspective depth, natural lighting, casual sketch composition, instructional yet playful

=== MOOD ===
Energetic, explanatory, slightly humorous, practical and easy to understand

Quality: High-resolution whiteboard illustration, clear visual hierarchy, suitable for educational thumbnail or knowledge-sharing poster
```

**Fill-in rules:**
- Characters should evolve visually across steps: neutral robot → vest-wearing robot → graduation-cap robot (or equivalent progression)
- Props escalate in complexity: simple symbol → clipboard with structure → glowing badge with surrounding orbit icons
- Red and blue marker strokes are for emphasis only (vest, badge, key underlines) — black is the dominant line color
- Speech bubbles should be conversational and concise, as if scrawled on the spot
