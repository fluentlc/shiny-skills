# Style Template: 物品爆炸视图风格 (Technical Exploded View Diagram Style)

**Input format:** `解析[subject]结构, [aspect_ratio]` or `[subject] exploded view, [aspect_ratio]`

> ⚠️ This style is subject-specific, not topic-based. It does not follow the standard educational infographic format.

**Opening Line:**
```
Technical exploded view diagram, [aspect_ratio], featuring [subject].
```

**Sections:**

```
=== COMPOSITION & PERSPECTIVE ===
View: Isometric perspective (30-degree angle)
Layout: Deconstructed assembly, all individual components floating in space (expanded view)
Alignment: Parts aligned in logical assembly order along the central axis, revealing internal structure
Depth: Clear separation between layers to show how they fit together

=== COMPONENTS ===
Subject: [subject] broken down into key parts:
[List each major component on its own line, with sub-components in parentheses if relevant. Include Chinese names for each part.]

Detail: High mechanical precision, distinct geometry for each part

=== LABELS & ANNOTATIONS ===
Style: Clean leader lines pointing to major components
Text: 中文 labels for each component
Constraint: Professional engineering standard, legible sans-serif font

=== VISUAL STYLE ===
Aesthetic: Technical illustration style, similar to engineering blueprints or patent drawings
Lighting: Soft ambient occlusion shadows between floating parts to enhance depth perception
Background: Clean white

=== MOOD & QUALITY ===
Educational, industrial, precise, informative infographic aesthetic | 8k, ultra-detailed, technical masterpiece, sharp focus, engineering blueprint accuracy, labeled annotation clarity, isometric precision
```

**Fill-in rules:**
- Components should be listed in logical assembly order (outermost shell → internal boards → smallest chips)
- Use real component names where known; if unknown, use descriptive functional names in Chinese
- Leader lines should not overlap; arrange labels radially around the exploded assembly
- Each component should have visually distinct geometry and color-coding to aid identification
