```
Minimalist hand-drawn doodle style educational infographic, [aspect_ratio], explaining [topic].

**Sections:**

```
=== TITLE STYLE ===
"[topic]" in bold, casual handwritten marker font, enclosed in a hand-drawn speech bubble, banner, or cloud shape
Font color: black
Texture: Ink texture on paper

=== SCENE & LAYOUT ===
Composition: [choose one: step-by-step staircase flow / left-to-right timeline / radial burst from center]

=== MAIN CONTENT ===
[For each step, use STEP_N format]

[STEP_N]

Label: "[step name]" in neat handwritten print
[If not first step] Connection: [thick marker stroke curvy doodle arrow / dashed line with sparkles ✨ / dotted arrow] pointing from previous step

=== VISUAL STYLE ===
Material: Ink pen outlines (variable line weight), felt-tip marker or watercolor highlighter fills.
Render: 2D flat illustration, scanned sketchbook aesthetic, clean vector look.
Colors: White background dominates, with soft pastel accents ([choose 3: mint green, pale yellow, soft pink, baby blue, lavender, peach]) and bold black outlines for contrast.

=== DECORATIVE ELEMENTS ===
Small doodles (sparkles ✨, stars ★, lightbulbs 💡, exclamation marks !), squiggly lines, dots, washi tape textures, paper clips to fill negative space playfully.

=== MOOD ===
Friendly, organized, clear, cute, accessible, "smart-casual" learning vibe.

Quality: High-quality 2D vector art, clean lines, legible text, visually balanced layout.

**Fill-in rules:**
- Use progressively larger/bolder shapes as steps increase in complexity or abstraction
- Choose dashed lines + sparkles for "upgrade" connections, solid arrows for sequential steps
- Icons should be ultra-simple: 1–2 symbols maximum per step
