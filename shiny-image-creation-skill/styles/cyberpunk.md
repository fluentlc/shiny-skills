**Fill-in rules:**
- Each step should use a distinct neon accent color (e.g., cyan for step 1, magenta for step 2, gold for step 3) against the dark background
- Visual constructs should feel like real data infrastructure (API gateways, neural nexuses, skill capsule arrays) — technical, not decorative
- Background must stay dark and restrained; all brightness concentrated on foreground elements
- Connection arrows should feel like live data flows — pulsing, animated-looking cable traces or light beams
