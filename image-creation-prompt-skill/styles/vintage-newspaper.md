**Fill-in rules:**
- Headline must summarize the topic in a dramatic, journalistic tone; subheadline should contextualize it as a news story
- Main image should be described as a single cohesive illustration that encapsulates the entire topic narrative, not fragmented steps
- Byline name and title should feel plausible for the domain (e.g., tech → 首席AI架构师, science → 资深研究员)
- Lead paragraph must read like a real newspaper lede: answer "what happened / why it matters" in journalistic Chinese
- Secondary article titles should break the topic into 2–4 thematic angles, each with an editorial headline style
- The infographic sidebar should contain a relevant quantitative or comparative metric — invent plausible but realistic data if needed
- Advertisement should be loosely related to the topic domain (e.g., AI topic → AI tool ad, food topic → kitchen gadget ad)
- Accent colors in the visual style should be derived from the main image description's color progression
