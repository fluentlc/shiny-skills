**Fill-in rules:**
- Assign one distinct accent color per major concept or stage (e.g., blue for concept A, teal for concept B, purple for concept C) — use these consistently throughout all sections
- Each of the four quadrant sections (Left, Bottom Left, Right, Bottom Right) should map to a distinct analytical dimension of the topic
- The central node is the anchor — all sections radiate from it logically
- Panel titles should use the "[problem]→[solution]" or "[input]→[output]" pattern to create analytical clarity
- Icons should be hand-drawn style (not photographic) — simple, line-art, consistent weight
