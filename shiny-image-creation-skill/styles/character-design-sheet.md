# Style Template: 人物角色设定图 (Character Design Sheet Style)

**Input format:** `[character name and series], 人物角色设定图风格, [aspect_ratio]`

> ⚠️ This style generates a character design reference sheet, not an educational infographic. Input is a character name + series, not a topic.

**Opening Line:**
```
Generate a complete character design sheet for an original anime character: [character]. The sheet includes: 1) Three-view turnaround (front, side, back) showing full body proportions; 2) Expression sheet with 6 expressions (happy, angry, sad, surprised, determined, shy); 3) Pose sheet with 4 action poses ([pose1], [pose2], [pose3], [pose4]); 4) Costume variations ([costume1], [costume2], [costume3]).
```

**Sections:**

```
Clean white background, anime illustration style, clearly labeled sections, professional character design layout.

| [character-specific quality tags]:
[Describe the character's defining visual features:]
- Hair: [color, style, length, special properties like translucency or texture]
- Eyes: [color, shape, any glow or special properties in emotional moments]
- Skin: [tone, any distinctive features]
- Signature outfit: [describe the primary costume in detail — material, color, logo, texture]
- Costume variations: [list 3 outfits with brief descriptions]
- Posture and demeanor: [default body language, forward lean / upright / relaxed]
- Expression style: [emotional range — reserved / expressive / intense]
- Lighting signature: [how light interacts with their design — ambient glow, reflected highlights, muted palette with accents]
- Palette: [primary and accent colors, overall temperature]
- Linework style: [cel-shading / soft shading / sketch / painterly]
- Framing: [consistent 16:9 layout optimized for character sheet readability]

| masterpiece, best quality, official anime production art, ultra-detailed, sharp focus, studio-quality lighting
```

**Fill-in rules:**
- Pose sheet should reflect the character's personality and narrative role (action poses for fighters, reading/study poses for intellectuals, etc.)
- Costume variations should cover different contexts: signature outfit, casual/daily wear, alternate scenario outfit (battle, formal, etc.)
- Quality tags should describe character-specific visual details — hair translucency, fabric texture, eye glow in emotional states — not generic quality words
- The sheet layout should be readable at 16:9 wide format: three-view on left, expressions top-right, poses bottom-right, costumes far right
