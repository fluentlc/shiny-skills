# shiny-image-creation-skill

[中文](./README.zh.md)

A skill that transforms simple image creation descriptions into detailed, structured AI image generation prompts.

## What It Does

Give it a one-line description — topic, style, and aspect ratio — and it outputs a complete, structured prompt ready to paste into Midjourney, DALL-E, Stable Diffusion, or any other AI image generator.

**Input:**
```
生成一张从Function Call到MCP到SKILL的发展历程图片，哆啦A梦风格，16:9
```

**Output:** A fully structured prompt covering title typography, scene layout, main content sections, visual style, decorative elements, mood, and quality tags.

## Recommended Image Generators

The prompts generated by this skill have been tested and work best with:Banan2 / Banana Pro, They also work with Midjourney, DALL-E, and Stable Diffusion, but the style fidelity may vary.

## Installation

This skill requires file reading capability in your agent (Claude Code / OpenClaw or equivalent). The entire skill directory must be accessible, not just `SKILL.md`.

```bash
# Clone the repo
git clone https://github.com/fluentlc/shiny-skills.git

# Copy the skill directory to your Claude Code skills folder
cp -r shiny-skills/shiny-image-creation-skill ~/.claude/skills/
```

## Usage

After installation, describe your image in natural language:

```
生成一张 [topic]，[style]，[aspect ratio]
```

Claude will detect the skill, match the style, load the corresponding template, and generate the prompt.
