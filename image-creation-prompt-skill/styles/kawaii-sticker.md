**Fill-in rules:**
- Use a single evolving chibi character across all steps to create visual continuity (same robot/character that upgrades at each step)
- Each step should show clear visual transformation: simple form → badge upgrade → full power transformation with aura/confetti
- Connection arrows between steps should feel celebratory: pink ribbons for sequential, rainbow arcs for "level up" moments
- Decorations should be dense but not cluttered — fill corners and negative space, never overlap the character or label
