**Fill-in rules:**
- This style generates a collectible blind-box style display; input is a character type or profession
- Character design must use chibi proportions (exaggerated head-to-body ratio, roughly 2–3 heads tall) with clean, rounded shapes
- The scene should be framed like a product display case — equal vertical split is the default, but accept variations (single panel, triptych)
- Left panel always contains the character figure; right panel contains 3–5 related items/props arranged neatly
- Neon sign text should be the topic name or a thematic label in all caps (e.g., "PROGRAMMER", "DESIGNER")
- Neon colors default to rainbow gradient or a single bold accent color; match the character's color palette
- Props must be instantly recognizable professional items (laptop + keyboard + headphones + coffee cup for a programmer)
- Background should be neutral (light gray, off-white, or soft pastel) to keep focus on the figure and props
- Lighting must be clean and modern — soft ambient with subtle rim highlights, not dramatic or moody
- Overall aesthetic is "cute collectible toy photography" — think Pop Mart, Sonny Angel, or similar blind box brands
