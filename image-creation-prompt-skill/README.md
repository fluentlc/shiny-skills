# image-creation-prompt-skill

[中文](./README.zh.md)

A skill that transforms simple image creation descriptions into detailed, structured AI image generation prompts.

## What It Does

Give it a one-line description — topic, style, and aspect ratio — and it outputs a complete, structured prompt ready to paste into Nano Banana Pro, Midjourney, DALL-E, Stable Diffusion, or any other AI image generator.

**Input:**
```
Create an image showing the evolution from Function Call to MCP to SKILL, Doraemon style, 16:9
```

**Output:** A fully structured prompt covering title typography, scene layout, main content sections, visual style, decorative elements, mood, and quality tags.

## Recommended Image Generators

The prompts generated by this skill have been tested and work best with Banana2 / Banana Pro. They also work with Midjourney, DALL-E, and Stable Diffusion, but style fidelity may vary.

## Installation

This skill requires file reading capability in your agent (Claude Code / OpenClaw or equivalent). The entire skill directory must be accessible, not just `SKILL.md`.

```bash
# Clone the repo
git clone https://github.com/fluentlc/shiny-skills.git

# Copy the skill directory to your skills folder
cp -r shiny-skills/image-creation-prompt-skill ~/.claude/skills/
```

## Usage

After installation, describe your image in natural language:

```
Create an image of [topic], [style], [aspect ratio]
```

The agent will detect the skill, match the style, load the corresponding template, and generate the prompt.

## Example

**Input:**
```
Create an image showing the evolution from Function Call to MCP to SKILL, chalkboard style, 16:9
```

**Output (excerpt):**
```
Chalkboard art style educational infographic, 16:9, explaining the evolution from Function Call to MCP to SKILL.

=== TITLE STYLE ===
"The Evolution from Function Call to MCP to SKILL" in bold hand-lettered chalk typography...

=== MAIN CONTENT ===
[STEP_1]
Visual: A simple rectangular box labeled "Function Call"...
```
